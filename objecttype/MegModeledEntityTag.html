MegModeledEntityTag

Prefix:megmodeledentity@Identity Format:Identified using the format megmodeledentity@<entity>.Description:A modeled entity doesn't necessarily have to have a model, and it can have multiple models.View source

Tags​

Tag: MegModeledEntityTag.body_clamp_uneven​

ReturnsElementTag(Boolean)Mechanismbody_clamp_unevenDescriptionReturns whether the body clamp is uneven on the modeled entity. Body clamp is used to clamp the body when the entity is standing still.See AlsoMegModeledEntity.max_body_angle
MegModeledEntity.min_body_angle

Tag: MegModeledEntityTag.entity​

ReturnsEntityTagDescriptionReturns the underlying entity of the modeled entity.

Tag: MegModeledEntityTag.entity_visible​

ReturnsElementTag(Boolean)Mechanismentity_visibleDescriptionReturns whether the base entity of the modeled entity is visible.

Tag: MegModeledEntityTag.head_clamp_uneven​

ReturnsElementTag(Boolean)Mechanismhead_clamp_unevenDescriptionReturns whether the head clamp is uneven on the modeled entity. Head clamp is used to clamp the head when the entity is moving. See also: MegModeledEntity.max_body_angleSee also: MegModeledEntity.min_body_angle

Tag: MegModeledEntityTag.max_body_angle​

ReturnsElementTag(Number)Mechanismmax_body_angleDescriptionReturns a ElementTag(Number) of the current maximum body angle of this entity. See also MegModeledEntity.min_body_angle

Tag: MegModeledEntityTag.max_head_angle​

ReturnsElementTag(Number)Mechanismmax_head_angleDescriptionReturns a ElementTag(Number) of the current maximum head angle of this entity. See also MegModeledEntity.min_head_angle

Tag: MegModeledEntityTag.min_body_angle​

ReturnsElementTag(Number)Mechanismmin_body_angleDescriptionReturns a ElementTag(Number) of the current minimum body angle of this entity. See also MegModeledEntity.max_head_angle

Tag: MegModeledEntityTag.min_head_angle​

ReturnsElementTag(Number)Mechanismmin_head_angleDescriptionReturns a ElementTag(Number) of the current minimum head angle of this entity. See also MegModeledEntity.max_head_angle

Tag: MegModeledEntityTag.model[(<model>)]​

ReturnsMegActiveModelTagDescriptionReturns the active model with the specified name on the modeled entity. If no name is specified, returns the first model on the modeled entity.

Tag: MegModeledEntityTag.models​

ReturnsMapTag(MegActiveModelTag)DescriptionReturns a map of all models on the modeled entity. The keys are the names of the models, and the values are the active models.

Tag: MegModeledEntityTag.player_mode​

ReturnsElementTag(Boolean)Mechanismplayer_modeDescriptionReturns a ElementTag(Boolean) of whether the body will rotate like a player (i.e. will not try to match the head angle).

Tag: MegModeledEntityTag.rotation_delay​

ReturnsDurationTagMechanismrotation_delayDescriptionReturns a DurationTag of the delay before the body auto rotates to match the head's rotation. See also MegModeledEntity.rotation_duration

Tag: MegModeledEntityTag.rotation_duration​

ReturnsDurationTagMechanismrotation_durationDescriptionReturns a DurationTag the body takes to auto rotate back to the head's rotation. See also MegModeledEntity.rotation_delay

Tag: MegModeledEntityTag.should_save​

ReturnsElementTag(Boolean)Mechanismshould_saveDescriptionReturns whether the modeled entity should be saved on unload.

Tag: MegModeledEntityTag.stable_angle​

ReturnsElementTag(Number)Mechanismstable_angleDescriptionReturns the angle in degrees where the body rotation can exceed the clamp before snapping towards the clamped values.

Tag: MegModeledEntityTag.visible_to​

ReturnsListTag(PlayerTag)Mechanismvisible_toDescriptionReturns a list of players that can see the modeled entity. See also hide_fromSee also show_to

InputElementTag(Booelan)DescriptionSets whether the base entity of the modeled entity is visible.TagsMegModeledEntity.entity_visible

Mech: MegModeledEntityTag.head_clamp_uneven​

InputElementTag(Booelan)DescriptionSets whether the head clamp is uneven on the modeled entity. Head clamp is used to clamp the head when the entity is moving.TagsMegModeledEntity.head_clamp_uneven

Mech: MegModeledEntityTag.hide_from​

InputListTag(PlayerTag)DescriptionForces the modeled entity to be hidden from the input list of players. See also show_toSee also visible_to

Mech: MegModeledEntityTag.max_body_angle​

InputElementTag(Number)DescriptionSets the maximum body angle of the modeled entity. If body_clamp_uneven is false, the minimum body angle will be set as the negative of this value.TagsMegModeledEntity.max_body_angle

Mech: MegModeledEntityTag.max_head_angle​

InputElementTag(Number)DescriptionSets the maximum head angle of the modeled entity. If head_clamp_uneven is false, the minimum head angle will be set as the negative of this value.TagsMegModeledEntity.max_head_angle

Mech: MegModeledEntityTag.min_body_angle​

InputElementTag(Number)DescriptionSets the minimum body angle of the modeled entity. Will have no effect if body_clamp_uneven is false.TagsMegModeledEntity.min_body_angle

Mech: MegModeledEntityTag.min_head_angle​

InputElementTag(Number)DescriptionSets the minimum head angle of the modeled entity. Will have no effect if head_clamp_uneven is false.TagsMegModeledEntity.min_head_angle

Mech: MegModeledEntityTag.rotation_delay​

InputDurationTagDescriptionSets the delay before the body auto rotates to match the head's rotation. See also rotation_delayTagsMegModeledEntity.rotation_delay

Mech: MegModeledEntityTag.rotation_duration​

InputDurationTagDescriptionSets the time it takes for the body to auto rotate to match the head's rotation. See also rotation_delayTagsMegModeledEntity.rotation_duration

Mech: MegModeledEntityTag.player_mode​

InputElementTag(Boolean)DescriptionSets whether the body will rotate like a player (i.e. will not try to match the head angle).TagsMegModeledEntity.player_mode

Mech: MegModeledEntityTag.show_to​

InputPlayerTagDescriptionForces the modeled entity to be unhidden from the input player. See also hide_fromSee also visible_to

Mech: MegModeledEntityTag.should_save​

InputElementTag(Boolean)DescriptionSets whether the modeled entity should be saved on unload.TagsMegModeledEntity.should_save

Mech: MegModeledEntityTag.stable_angle​

InputElementTag(Number)DescriptionSets the stable angle before correcting back to the clamped angle. For example, if the clamp is 50, and the stable angle is 15, the body can be 65 degrees away from the head before snapping back to 50 degrees away. This causes the "sudden jerk" effect on all entity body rotation.TagsMegModeledEntity.stable_angle
