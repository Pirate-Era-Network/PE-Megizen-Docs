PEMountTag

Prefix:pemount@Identity Format:Identified using the format pemount@<uuid>. For example, pemount@1234-1234-1234.Description:A PEMountTag represents a pemount entity in the world.See also:pemountView source

Tags​

Tag: PEMountTag.mount_info​

ReturnsMapTagDescriptionReturns the current mount settings as a map.

Tag: PEMountTag.mount_string​

ReturnsElementTagDescriptionReturns the mount settings as a formatted string.

Tag: PEMountTag.driver​

ReturnsEntityTagDescriptionReturns the driver of the mount. Empty when the mount has no driver.

Tag: PEMountTag.entity​

ReturnsEntityTagDescriptionReturns the entity of the pemount.

Tag: PEMountTag.is_moving​

ReturnsElementTag(Boolean)DescriptionReturns whether the mount is moving.

Tag: PEMountTag.is_flying​

ReturnsElementTag(Boolean)DescriptionReturns whether the mount is flying.

Tag: PEMountTag.is_swimming​

ReturnsElementTag(Boolean)DescriptionReturns whether the mount is swimming.

Tag: PEMountTag.current_state​

ReturnsElementTagDescriptionReturns the animation state the mount is in.

Tag: PEMountTag.can_move​

ReturnsElementTag(Boolean)DescriptionReturns whether the mount can currently move.

Tag: PEMountTag.passengers​

ReturnsListTagDescriptionReturns the passengers currently on the mount.

Tag: PEMountTag.has_passengers​

ReturnsElementTag(Boolean)DescriptionReturns whether the mount has passengers.
